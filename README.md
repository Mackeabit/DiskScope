# DiskScope

![DiskScope](DiskScope.png)

Windows용 읽기 전용 디스크 공간 탐색기입니다. 드라이브·폴더를 스캔하고, 큰 파일과 공간 분포를 목록·트리맵으로 살펴보세요. 한국어 UI와 다크 테마를 제공합니다.

## 다운로드와 실행

[Windows x64 ZIP 다운로드](https://github.com/Mackeabit/DiskScope/releases/download/v0.1.0-preview.1/DiskScope-0.1.0-preview.1-win-x64.zip) · [SHA-256](https://github.com/Mackeabit/DiskScope/releases/download/v0.1.0-preview.1/SHA256SUMS.txt) · [릴리스 안내](https://github.com/Mackeabit/DiskScope/releases/tag/v0.1.0-preview.1)

ZIP 전체를 압축 해제하고 최상위 **`DiskScope.App.exe`**를 실행하세요. 함께 있는 **`app` 폴더를 유지**해야 합니다. 관리자 권한이나 별도 런타임·폰트 설치는 필요하지 않습니다.

## 사용법

1. 드라이브나 폴더를 선택하고 **스캔 시작**을 누릅니다. 스캔 중 **취소**할 수 있습니다.
2. 폴더를 더블클릭하거나 Enter로 열고, Alt+↑로 상위 폴더로 이동합니다. 검색·확장자 필터로 결과를 좁힐 수 있습니다.
3. 항목을 우클릭하거나 **탐색기에서 열기** 버튼으로 실제 위치를 엽니다.
4. 외부에서 파일을 삭제·이동했다면 **다시 스캔 / F5**로 갱신하세요. 결과는 실시간으로 바뀌지 않습니다.

## 용량 표시

- **논리 크기:** 파일 이름별 데이터 크기입니다. 같은 파일을 가리키는 하드링크도 이름마다 셉니다.
- **고유 할당:** 실제 할당 공간에서 하드링크 중복을 제외한 값입니다. 별칭은 0 B로 표시될 수 있으며, 삭제해서 확보되는 공간과는 다릅니다.
- **미확인:** 접근 거부·제외·변경 등으로 계산하지 못한 부분입니다. 항목 개수는 누락된 용량을 뜻하지 않습니다.

보호된 항목·시스템 데이터·스캔 중 변경 때문에 합계가 드라이브 사용량과 다를 수 있습니다. 연결된 폴더와 클라우드·오프라인 표식이 있는 항목은 기본적으로 제외합니다.

## 미리보기 참고사항

현재 버전은 **0.1.0-preview.1**입니다. Windows 10 22H2 x64에서 확인했으며 Windows 11과 개발 도구·런타임이 없는 PC에서는 아직 검증하지 않았습니다. 화면 읽기 프로그램·다중 모니터 DPI·클라우드 환경도 추가 확인이 필요합니다.

실행 파일은 **미서명** 상태로 Windows 보안 경고가 표시될 수 있습니다. 로컬 드라이브·폴더를 일반 권한으로 스캔하며 파일 삭제·정리, 네트워크 스캔, 관리자 전용 스캔은 제공하지 않습니다.

스캔 결과를 외부로 전송하지 않습니다. 오류 로그를 공유할 때는 경로 등 개인정보를 확인해 주세요. [보안·개인정보 안내](SECURITY.md)
